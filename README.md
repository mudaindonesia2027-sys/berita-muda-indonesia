# BERITA MUDA INDONESIA — FINAL PRODUCTION

Ini adalah **satu Master Project** untuk proses akhir sampai deployment production. Paket ini menggabungkan fondasi website berita, video, Supabase, intelligent news, community moderation, monetization foundation, automation, SEO, dan Vercel deployment.

## Jalankan lokal
1. Salin `.env.example` menjadi `.env` dan isi nilai nyata.
2. Install dependency: `npm install`
3. Jalankan migration database berurutan.
4. Jalankan: `npm run dev`
5. Cek: `/health`

## Production
Ikuti `DEPLOYMENT-CHECKLIST.md`. Jangan menganggap aplikasi sudah live hanya dengan meng-upload ZIP; layanan Supabase, OAuth, sumber RSS, environment variables, dan deployment harus dikonfigurasi serta diuji.
